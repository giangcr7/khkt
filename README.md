# Research Management System

A web application for managing research topics and academic projects.

The system allows students and lecturers to submit, review, and manage research topics.

---

## Tech Stack

Backend

* NestJS
* PostgreSQL
* Prisma ORM

Frontend

* React
* Ant Design

---

## Features

* Research topic submission
* Topic approval workflow
* Lecturer supervision
* Student progress tracking
* Document management

---

## Installation

Clone repository

```
git clone https://github.com/giangcr7/khkt.git
```

Install dependencies

```
npm install
```

Run the project

```
npm run start
```
